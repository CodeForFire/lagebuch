The Android app now uses the package name `de.codeforfire.lagebuch.app`, so it installs as a new app beside an older Lagebuch from a GitHub APK or the Play test and starts empty: Einsatzdateien and Stammdaten have to be exported from the old app and imported again before it is uninstalled, Kartenpakete are downloaded again in the Stammdaten editor, and joined hosts are pinned again on first connection.
