The Einsatz sidebar is built from Stammdaten: it shows the modules the **Navigation** category
leaves switched on, in that order, with each Checkliste in its configured place. A Checkliste's
tab carries its own name, as does the heading above its items (where it used to read
"CHECKLISTE"). Opening an older Einsatz still shows every Checkliste that file holds, even one
created or deleted in Stammdaten since. The ETB is always shown.
